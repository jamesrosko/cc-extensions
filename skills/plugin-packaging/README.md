# plugin-packaging

Bundles skills, subagents, commands, hooks, and MCP servers into an installable Claude Code plugin. It creates the manifest, lays out components correctly, fixes paths, optionally adds a marketplace file, and validates the result.

## Install
Copy this folder to `~/.claude/skills/plugin-packaging/` (user) or `.claude/skills/plugin-packaging/` (project).

## Use
Ask "package these skills as a plugin" or "why isn't my installed plugin loading its agents".
