# session-handoff

Writes a `HANDOFF.md` capturing goal, state, decisions, open questions, and next steps, based on the real git state, so a fresh session can resume the work.

## Install
Copy this folder to `~/.claude/skills/session-handoff/` (user) or `.claude/skills/session-handoff/` (project).

## Use
Say "write a handoff" before ending a session. Start the next one with "Read HANDOFF.md and continue."
